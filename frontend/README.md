# frontend/ — 用户输入界面

一个单页 Web 界面，让用户用一句话描述生成游戏，并在右侧 iframe 预览。对应实验要求 5 的前端界面部分。

## 核心思路

左侧输入面板 + 右侧预览区的经典布局：用户输入描述 → 调后端接口生成游戏 → 把返回的游戏 URL 塞进 iframe 实时预览。前端只管交互与展示，生成逻辑全在后端 `agent/` 流水线。

## 唯一文件：`index.html`

纯静态 HTML + 内联 CSS/JS，无构建步骤。

### 结构
- **输入面板**：文本域（含默认示例文案）、几个可点击的示例提示（点了自动填入文本域）、生成按钮、状态行。
- **预览区**：一个铺满的 `iframe`，用于显示生成的游戏。

### 交互逻辑
点"生成游戏"后：
1. 取文本域内容，禁用按钮并显示"生成中"状态；
2. `POST` 到 `/api/generate`，body 为 `{ description }`；
3. 收到 `{ url, title }` 则把 `url` 设为 iframe 的 src 完成预览；收到 `{ error }` 或请求失败则在状态行报错；
4. 无论成败都重新启用按钮。

## 现状与缺口
