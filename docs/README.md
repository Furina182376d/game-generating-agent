# docs/ — 文档

项目的过程文档与最终交付文档。对应实验要求 4「每周固定时间汇报，最终完成技术总结报告和 PPT」。

## 核心思路

把"过程留痕"和"最终交付"分开管理：周报记录每周进展与风险，供每周汇报；最终技术报告与 PPT 是验收交付物。

## 目录结构

```
docs/
└── weekly/          周报，每周一份
    └── week01.md    第 1 周：需求分析、技术选型、项目骨架、端到端雏形
```

## 约定
- **周报**：放 `weekly/weekNN.md`，建议固定三段式——本周工作 / 下周计划 / 风险与待确认。
- **最终技术报告**：验收前补 `docs/report.md`（或 PDF），涵盖系统架构、各阶段实现、验收结果与已知缺口。
- **汇报 PPT**：验收用，可另存或链接到此目录。
